Small-stack sweep benchmark
============================

One thin film (n=3.5, d=1 µm) with a 50×50 wavelength–kx sweep.
Same six-subsection structure as the single-point benchmark but with
vectorised inputs to exercise batched solve paths.

.. GENERATED FROM PYTHON SOURCE LINES 11-16

Setup
-----
A single high-index layer between air media.  We sweep 50 wavelengths
(400–800 nm) × 50 in-plane wavevectors (0–1e7 rad/m) at TE
polarisation.
