==========
Benchmarks
==========

Method-vs-method and backend-vs-backend performance comparisons
for the stratix solver.

Each gallery example compares solve time, memory, and numerical
correctness across solver methods (Abélès, Admittance, DTN, S-matrix)
and backends (NumPy, JAX, PyTorch, Autograd).
